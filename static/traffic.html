Every request to bioconductor.org gets a traffic class from rule-based, versioned rules (browser, R and other package clients, crawlers, mirrors, CI, monitoring, likely automated). Counts are per UTC day. A client is one network address, counted through a salted hash; no addresses are published. The dashed line marks the site's move from CloudFront to Cloudflare: from there the rules also see network (ASN) and verified-bot labels, so class totals step at that line by design. They are not smoothed.
